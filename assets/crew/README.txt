Portraits d'équipiers en image (optionnel)
==========================================
Aucune image n'est fournie : le jeu dessine des portraits vectoriels provisoires (js/portraits.js).
Pour de vraies illustrations : génère-les avec les prompts de PROMPTS_IMAGES.md, dépose-les dans ce dossier
(3 formats par personnage : card 6:7, thumb 1:1, full 2:3), puis déclare-les dans manifest.js.
